# Govern production affiliate agents through an internal gateway

Production Coverage Planners, Mapping Producers, and Independent Supply Reviewers run as disposable single-job Codex invocations behind a dedicated internal-only Agent Gateway. Agent containers receive claim-scoped evidence, a short-lived result token, and model credentials, but no production database, storage, provider, repository, or unrestricted backend credentials. Persistent unprivileged supervisors request role-scoped work; the gateway owns queue leases, generations, idempotency, provider and capture execution, mapping validation, lifecycle writes, evidence persistence, operational events, and containment.

Three disjoint typed queues replace shared first-claim-wins production work. Runtime prompts are generated from machine-readable role contracts and the active Supply Contract, and each invocation handles exactly one claim before its temporary workspace is destroyed. Independent review uses a different worker and invocation, a fresh context, and a read-only committed package. The open-weight stack remains offline for evaluation and training artifacts only.

This extra internal module is intentional: prompt instructions are not an authority boundary. Database permissions, isolated networks, scoped tokens, compare-and-set generations, and gateway validation make prohibited writes structurally unavailable. The affiliate admin surface is read-only; human-directed actions are executed by an agent through the same governed lifecycle interface and retain the human and executing-agent identities.
