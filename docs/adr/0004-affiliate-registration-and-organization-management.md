# Define Affiliate Events by External Registration, not Event Type

Affiliate Event is a commercial context equivalent to External Registration and independent of Event Type, Event Provenance, Management Authority, and Resource Source. Organization-created Affiliate Events require a verified Tracking Pixel for the destination domain, while platform-sourced Events can track outbound clicks before an external operator verifies purchase attribution.

Organization Claim makes the Organization the Management Authority and initially assigns its owner as Event Host for every Organization Event without changing Registration Destination or Schedule. Switching to BracketIQ registration removes the Affiliate Event classification but preserves competition, Resources, Schedule, provenance, authority, and historical attribution.
