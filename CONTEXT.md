# BracketIQ Events

BracketIQ Events models organizer-managed activities from configuration through creation and scheduling.

## Language

**Event**:
An organizer-managed activity with one lifecycle shared across its supported types.
_Avoid_: Listing, competition

**Event Type**:
A classification that determines which parts of an Event Configuration apply. An Event Type does not define a separate Event lifecycle.
_Avoid_: Event kind, separate event model

The five Event Types are One-Time Event, Weekly Event, League, Tournament, and Tryout.

**Event Configuration**:
The complete set of organizer-intended values from which an Event is created. A saved draft can contain an Event Configuration but is not synonymous with it.
_Avoid_: Form values, snapshot, draft reference, payload

**Automated Scheduling**:
A lasting Event property that permits Schedule creation and maintenance. When disabled, Match placements are frozen, Build Schedule, Complete Schedule, Rebuild Schedule, and Schedule Reflow are unavailable, and only explicit Match edits can change them.
_Avoid_: Schedule Later, automated schedule build, create mode

**Planned End**:
The explicit date and time when an Event is expected to end.
_Avoid_: Fixed end datetime

**End Policy**:
The rule governing an Event's end: Planned End, Set End from Schedule, or No Planned End.
_Avoid_: No fixed end datetime

**Set End from Schedule**:
An End Policy under which Build Schedule and Rebuild Schedule set a League or Tournament's end from its latest scheduled Match.
_Avoid_: Schedule-Generated End

**No Planned End**:
An End Policy for an unbounded Weekly Event that remains active until ended or archived by an organizer.
_Avoid_: Schedule-Generated End, infinite Event

**One-Time Event**:
An Event Type with one explicit time range and no generated matches or occurrences.
_Avoid_: Event

**Schedule**:
The Match Graph and its time, Resource, and officiating assignments for a League or Tournament, or the Occurrences of a Weekly Event. It is not an independent Event-owned lifecycle entity.
_Avoid_: Calendar, Schedule record

**Schedule Proposal**:
An unaccepted scheduling result containing the complete Match graph, proposed placements, and any Unscheduled Matches.
_Avoid_: Schedule preview

**Partial Schedule**:
An explicitly accepted Schedule containing one or more Unscheduled Matches.
_Avoid_: Failed Schedule

**Unscheduled Match**:
A Match in the complete competition graph that has no assigned time or Resource.
_Avoid_: Missing Match, scheduling failure

**Match Graph**:
The complete set of Matches and advancement dependencies generated by configured Phase Divisions before scheduling.
_Avoid_: Schedule, Match Demand

**Restricting Factor**:
A constraint that lowers possible Match concurrency, such as Resource, Team, or official availability. It is explanatory context, not proof that the constraint caused a specific Match to remain unscheduled.
_Avoid_: Root cause, capacity

**Build Schedule**:
An explicit operation that generates the Match Graph and assigns times, Resources, and officiating coverage for an Event while Automated Scheduling is enabled. It is separate from Event Creation.
_Avoid_: Schedule Later

**Complete Schedule**:
An operation that attempts to place only Unscheduled Matches while treating every scheduled Match as fixed.
_Avoid_: Rebuild Schedule

**Rebuild Schedule**:
An explicit operation that recomputes Match placements from the Event's current scheduling inputs while Automated Scheduling is enabled.
_Avoid_: Reschedule

**Schedule Reflow**:
An atomic Tournament adjustment after a Match completes that moves only affected, unlocked, unstarted Matches earlier or later to their earliest feasible times. It prefers reassigning eligible officials over moving Matches and updates a schedule-set Event end when the latest Match moves, without changing the bracket, seeding, match order, eligibility, or unaffected Matches.
_Avoid_: Rebuild Schedule, regenerate tournament

**Locked Match**:
A Match that Schedule Reflow cannot move or reassign. In-progress and completed Matches are inherently locked; an organizer can explicitly lock a future Match.
_Avoid_: Published Match, manually edited Match

**Registration Unit**:
The kind of participant accepted by an Event: an individual or a Team. One-Time and Weekly Events allow either; Leagues and Tournaments require Teams; Tryouts require individuals.
_Avoid_: Team signup

**Participant Registration**:
An accepted registration through which an individual or Team joins an Event, whether entered by the participant, imported, or created manually by an authorized organizer. The first Participant Registration locks the Event Type and Registration Unit, including after cancellation or refund.
_Avoid_: Checkout attempt, waitlist entry, free-agent application

**Registration Capacity**:
The maximum number of Registration Units an Event or Entry Division accepts. Team roster members and Phase Division entrants do not consume additional Registration Capacity.
_Avoid_: Max participants, roster limit

**Occurrence**:
One dated instance of a Weekly Event in its Schedule. Participant membership belongs to the Weekly Event, while attendance belongs to the Occurrence; an Occurrence is not a child Event.
_Avoid_: Child Event, Weekly Event instance

**Time Slot**:
Event availability resolved in one time zone and optionally restricted to eligible Resources and Divisions. A One-Time Time Slot resolves one local date and time range; a Repeating Time Slot resolves weekdays and local times across date bounds, with an end time no later than its start extending into the following local date.
_Avoid_: Capacity window

**Division**:
A group of Event participants who share eligibility, capacity, Resource, and competition rules.
_Avoid_: Competition Phase

**Entry Division**:
A Division selected during Participant Registration that owns registration eligibility and capacity.
_Avoid_: Registration category

**Phase Division**:
A Division created for one Competition Phase that owns the phase's participants, Resources, rules, and Match settings. Its participants are seeded or advanced from an Entry Division or an earlier Phase Division.
_Avoid_: Entry Division, Competition Phase

**Competition Phase**:
A stage through which participants compete or advance, such as League, Pool, Bracket, or Playoff. Each Competition Phase is represented by its own Division so it can have distinct rules and Match settings.
_Avoid_: Round, Division

**External Registration**:
A registration journey completed outside BracketIQ on the Event operator's site. An Event with External Registration is an Affiliate Event.
_Avoid_: Affiliate Event Type

**Affiliate Event**:
An Event with an externally completed, tracked registration journey. Affiliate Event is a commercial context independent of Event Type.
_Avoid_: Affiliate Event Type

**Resource**:
A schedulable playing area on which a Match or Occurrence takes place. Product interfaces use the Sport's Resource Label instead of hard-coding Field or Court.
_Avoid_: Field, Court

**Facility**:
A venue that contains one or more Resources.
_Avoid_: Resource

**Rental Booking**:
An agreement owned by a User or Organization that grants access to Resources during specified Time Slots. It has a separate lifecycle and can be selected as a Resource Source for an Event.
_Avoid_: Resource, Facility

**Resource Label**:
A Sport's singular and plural user-facing names for a Resource, such as Court and Courts for volleyball or Field and Fields for soccer.
_Avoid_: Resource type

**Tracking Pixel**:
A verified integration on an external registration domain that attributes Affiliate Event conversions. An Organization must verify a Tracking Pixel before enabling External Registration for that domain.
_Avoid_: Affiliate source

**Management Authority**:
The Organization or external operator responsible for Event operations.
_Avoid_: Event source

**Event Provenance**:
How an Event entered BracketIQ: Organization-created, user-created, or platform-sourced/imported. Provenance does not determine Event Type, External Registration, Management Authority, or Resource Source.
_Avoid_: Affiliate Source

**Organization Claim**:
The transfer of an Organization to its verified owner. Claiming makes the Organization the Management Authority and assigns its owner as Event Host for every Organization Event without changing Registration Destination or Schedule.
_Avoid_: Event claim

**Event Host**:
The authorized Organization member responsible for administering an Event on behalf of its Management Authority. The Organization owner can delegate Event Host responsibility without transferring Organization ownership.
_Avoid_: Management Authority, Event owner

**Resource Source**:
The origin of an Event's Resources and Time Slots: Organization-controlled or rental-backed.
_Avoid_: Management Authority

**Event Template**:
A reusable starting Event Configuration whose copied values remain editable unless another domain rule locks them.
_Avoid_: Immutable configuration, Rental Booking

**Officiating Plan**:
A Phase Division's Team officiating duties and named Official Positions for each Match, governed by one Staffing Priority.
_Avoid_: Officiating mode

**Official Position**:
A named officiating role with its own eligibility and certification requirements.
_Avoid_: Official

**Staffing Priority**:
The host's choice among Full Coverage Required, Team Coverage Required, Official Coverage Required, Best Available Coverage, and Full Coverage with Conflicts Allowed. It determines which officiating constraints can leave a Match unscheduled.
_Avoid_: Official scheduling mode, staffing mode
